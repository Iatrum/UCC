# Task 1010 — CI tests

## GitHub Actions and local verification

CI runs on pull requests targeting `dev` or `main` and on pushes to either branch. `unit-tests` runs `bun test tests/unit --isolate` using Bun 1.4.4 and the frozen lockfile. `lint-and-build` uses Node 22, runs `tsc --noEmit -p tsconfig.lint.json` as a named step, then runs the existing lint gate and build. Both jobs run without Actions secrets.

Local measurements on the `origin/dev` base were 4 seconds for dependency install, 8 seconds for 1,477 unit tests, 20 seconds for a cold typecheck, 6 seconds for changed-file ESLint, and about 90 seconds for the production-mode build. Actionlint passed. The earlier 1,496 count includes work on PR #379. CI runs the directory as it exists on the checked-out ref, with no count filter.

The first hosted run exposed 26 order-dependent failures. Replaying GitHub's file order reproduced all 26 locally. Bun's per-file isolation gives each file a fresh module registry. It also exposed the checkout test's incomplete consultation service mock, which now preserves the real `withSignLock` export. The isolated suite passed all 1,477 tests locally in about 6 seconds.

## Clinic journey

The spec, dedicated Playwright config, and login helper match the files on [PR #379](https://github.com/Iatrum/UCC/pull/379). The assertions depend on #379's registration and workflow toasts, allergy persistence, staff picker, treatment quantity, queue closure, complaint history and document listing. On current `dev` the dedicated run is expected to fail. Keep this check out of branch protection until #379 lands and the dedicated runner has passed in its CI environment.

Medplum supplies a Docker stack, but an empty stack lacks the UCC project, service client, and fake clinic and doctor membership needed by this spec. The repository's staging seed expects a provisioned project and login; its bootstrap does not create memberships or credentials. The supported path for this PR is a foreground local command against already-provisioned fake dev Medplum at `127.0.0.1:8113`. The runner builds and starts one loopback app, checks readiness, runs the journey once, propagates its result and stops its own app. The general Playwright gate reserves the journey for this dedicated runner.

Install dependencies with `bun install --frozen-lockfile` and install Chromium with `node_modules/.bin/playwright install chromium` if needed. Export fake-project credentials from your private environment, then run from the repository root:

```bash
bash e2e/scripts/run-clinic-journey.sh
```

The command requires `UCC_USER`, `UCC_PASSWORD`, `MEDPLUM_CLIENT_ID` and `MEDPLUM_CLIENT_SECRET`. If the project needs an explicit project selector, set `NEXT_PUBLIC_MEDPLUM_PROJECT_ID` to its fake project ID. The clinic journey itself requires no Medplum admin login. For hosted use, configure the four required credential names as GitHub Actions secrets in the fake runner's environment, or generate them during an ephemeral bootstrap. The broader local clinic isolation and staff membership specs can also use `MEDPLUM_ADMIN_EMAIL` and `MEDPLUM_ADMIN_PASSWORD` for their dev admin login.
