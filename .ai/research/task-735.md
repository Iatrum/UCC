- The App Router documents rendering failures explicitly for expected request errors. React 19 Suspense does not handle Effect-based loads. [Next.js error handling](https://nextjs.org/docs/app/getting-started/error-handling), [React Suspense](https://react.dev/reference/react/Suspense)

The dashboard Billing Playwright case supplies an HTTP 500 directly and bypasses the real route. The clinic-scoped Appointments read already passes search errors to its route handler. [FHIR R4 search errors](https://hl7.org/fhir/R4/search.html#errors), [Medplum 5.2.8](https://github.com/medplum/medplum/releases/tag/v5.2.8), [Medplum searchResources](https://www.medplum.com/docs/sdk/core.medplumclient.searchresources)
